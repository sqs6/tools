# 自研工具 / Tools

> 我写的、能被别人直接用的东西。练习题留在 `study` 仓库，**能交付的工具放这里**。
> 每个工具都要满足：**一条命令能跑起来 + README 有用法 + 有示例输出**。

## 每个工具的目录结构（统一）

```
tools/
├── README.md          ← 是什么 / 怎么装 / 怎么用 / 示例输出 / 限制
├── src/ 或 *.py       ← 源码
├── examples/          ← 示例输入输出
└── requirements.txt   ← 依赖（Python 项目必须有）
```

## 起步选题（配学习进度）

| 什么时候 | 工具 | 技术 |
|---|---|---|
| 大一上 | 一个 C 命令行小工具（文件 / 文本统计） | C |
| 大一下 | 一个 Python 目录扫描 / 统计脚本 | Python |
| 大一下 | MiniOB 相关的小工具（解析器、格式化器） | C++ |
| 大二 | ELF / PE 头解析器（用 `struct`） | Python |

## README 模板（每个工具套这个）

```markdown
# 工具名 —— 一句话说明

## 是什么
（解决什么问题）

## 怎么装 / 怎么跑
（一条命令，别人能直接复制）

## 用法
（参数说明 + 例子）

## 示例输出
（真实运行结果，别手打）

## 限制
（不做什么、在什么场景下别用）
```

## 规矩

1. **不写拿来乱扫公网的脚本**——只针对授权靶场/自有环境
2. 危险操作默认**只读**，要删要改必须显式加参数
3. 每个工具发一个 GitHub Release，附上编译好的可执行文件（别人不用装编译器）
4. 版本号用 `v0.x.0`，别用 `final`、`new`
